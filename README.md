# SmartAIIntel — homepage preview

Approved visual direction for smartaiintel.com: an original international-news homepage inspired by clear newsroom layouts.

## Current stage
Design preview only. All sample headlines are illustrative and are not approved reporting. No content has been published to the domain by this upload. This package contains the approved homepage, not the earlier publication prototype or its starter articles.

## Files
- index.html: homepage structure
- styles.css: responsive desktop and mobile styling
- script.js: preview filters, search, menu and story-position dialogs
- assets/: locally stored illustrative photographs

Open index.html in a browser to preview. No installation or build step is required.

## Before production
Replace illustrative headlines and preview dialogs with approved editorial content and real article pages. Integrate the publishing system, policy and contact pages. Configure deployment separately. AdSense is not connected and no credentials or publisher IDs are included.

Photographs are illustrative Unsplash/Pexels assets. Review licensing, editorial suitability and attribution requirements before production.
